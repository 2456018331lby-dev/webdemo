# Smart Home System Delivery Checklist

## Scope

- [ ] MVP features are explicit
- [ ] Non-goals are explicit
- [ ] Device list is explicit

## Protocol

- [ ] Device identifiers are defined
- [ ] Command payloads are versioned
- [ ] Ack and error payloads are defined
- [ ] UART or SPI framing is defined

## Backend

- [ ] Auth model is defined
- [ ] RLS model is defined
- [ ] Device registry tables are defined
- [ ] Command queue tables are defined
- [ ] Telemetry ingest path is defined

## Frontend

- [ ] Main screens are listed
- [ ] Desired state versus reported state is modeled
- [ ] Offline and timeout states are designed

## Delivery

- [ ] Primary deployment target is chosen
- [ ] Monitoring plan exists
- [ ] Browser verification plan exists
- [ ] Release checklist exists
