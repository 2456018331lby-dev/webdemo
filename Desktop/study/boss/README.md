# 求职投递助手

本项目是一个本地优先的 Chrome Manifest V3 求职网页插件。当前 MVP 面向 BOSS 直聘优先实现岗位扫描、简历画像、岗位/公司评分、队列排序、dry-run 投递记录、黑名单和审计日志。

## 当前能力

- 解析粘贴的简历文本，从“求职意向/期望城市/行业意向/技能栈”等字段生成目标岗位、目标城市、技能、行业和经验年限画像，也支持手动补充。
- 在支持的网站页面扫描岗位卡片，目前 BOSS 直聘为首个可用适配器。
- 按“公司优先、岗位次之”排序队列：公司分、岗位分、薪酬分、休息/年假分都会展示。
- 队列会按公司分组显示公司排名，再在每个公司内部显示岗位排名；自动队列也按这个顺序执行。
- 评分覆盖薪资、奖金/绩效、福利、双休/大小周/单休、年假、公司信息、岗位标题、技能、城市和行业匹配。
- 为每条岗位提供“全网资料搜索”入口，用于进一步核查公司薪资、奖金、福利、休息制度、年假和加班信息。
- 可打开全网资料搜索，也可把当前打开的资料页捕获成本地公司研究记录。
- 研究记录会保留来源 URL、来源标题、摘要、置信度、薪资、奖金、福利、休息制度、年假和风险信号，并自动重新计算公司分、岗位分和队列排序。
- 同一公司/岗位的多条研究记录会合并计分：来源数、薪资、奖金、福利、休息制度、年假和风险信号共同影响排序，负面公开信号会拉低公司优先级。
- 默认 dry-run，只记录将要投递的岗位，不真实点击投递按钮。
- 人工确认模式会打开岗位详情页并高亮投递/沟通入口，等待用户自己确认。
- 自动模式会在每日上限、最小间隔、黑名单、页面安全检查都通过后，对当前队列项执行一次投递/沟通入口点击。
- 自动队列可以显式启动/停止；启动后使用 Chrome alarms 按安全间隔唤醒后台任务，逐条执行当前排序最高且可投递的岗位。
- 点击后只有识别到“投递成功/已沟通/发送成功”等成功信号才会把队列项标记完成；确认弹窗、选择简历、补充信息或未知结果会暂停为人工复核。
- 队列执行有每日上限、最小间隔、黑名单和安全暂停逻辑。
- 遇到验证码、登录要求、平台风险提示、缺少必填项等情况会暂停。

## 安全边界

- 不绕过验证码、登录限制、风控、反爬或平台保护。
- 不做隐身、反检测、批量骚扰或垃圾投递。
- 自动模式只做一次普通页面点击；不绕过确认弹窗、补充资料、验证码、登录页或平台风控提示。未识别到明确成功信号时不会假定投递成功。
- 定时自动队列必须由用户显式启动；策略切回 dry-run/人工确认后会停止。
- 捕获资料页只在用户点击插件按钮后对当前活动标签页执行，不在后台批量读取网页。
- 简历和队列数据默认保存在本地 `chrome.storage.local`。

## 开发命令

```bash
npm install
npm test
npm run typecheck
npm run build
```

## 加载插件

1. 运行 `npm run build`。
2. 打开 Chrome 的扩展程序管理页。
3. 开启开发者模式。
4. 选择“加载已解压的扩展程序”。
5. 选择 `apps/extension/dist`。

## 目录结构

- `packages/shared`: 简历解析、评分、公司研究记录、队列、审计、安全策略和平台适配器。
- `apps/extension`: MV3 manifest、background service worker、content script、popup 和 side panel。
